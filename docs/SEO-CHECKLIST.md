# Checklist SEO

- Confirmar el dominio final y las redirecciones HTTPS.
- Reemplazar imágenes provisionales y añadir sus metadatos sociales.
- Validar sitemap, robots y datos estructurados tras el despliegue.
- Completar razón social, correo de privacidad, horario y coordenadas.
- Revisar las páginas legales antes de producción.
