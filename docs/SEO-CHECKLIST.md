# Checklist SEO

## Antes de publicar

- [ ] Confirmar dominio canónico y redirección HTTPS.
- [ ] Completar razón social, correo de privacidad y datos corporativos pendientes.
- [ ] Sustituir imágenes provisionales y revisar texto alternativo.
- [ ] Verificar título y descripción únicos en páginas nuevas.
- [ ] Revisar contenido legal definitivo.

## Después de publicar

- [ ] Confirmar `sitemap.xml` y `robots.txt`.
- [ ] Validar datos estructurados LocalBusiness y BreadcrumbList.
- [ ] Confirmar canonicals con el dominio definitivo.
- [ ] Probar enlaces internos, teléfono, WhatsApp, Google Maps y formulario.
- [ ] Solicitar indexación en Google Search Console cuando corresponda.
