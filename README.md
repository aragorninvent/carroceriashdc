# Carrocerías HDC-Tiberi

Sitio corporativo Next.js para fabricación, montaje, reparación y mantención de carrocerías. La configuración de ambiente se encuentra en `.env.example`.

Pendientes de confirmar antes de producción: razón social, RUT, correo público, horario, coordenadas, redes sociales, fotografías definitivas, certificaciones, garantías y remitente verificado en Resend.
